chat2 preregistration, before any chat2 generation or evaluation
Scope: implement and test code; no GPU provisioning, no full models on this Mac, no figure.
Dataset: fixed author-written values and scoring synonyms in pairing/chat2.py. Each twin independently has an item with probability .75. Kind drawn uniformly from eligible kinds. Train: city/job/pet/food/hobby/instrument/weather/event; test: new values of these kinds and all values of mood/trip/book/sport. CHAT_TEST wording family only in test. Six original-model turns with partner item visible only to privileged teacher; same clean/META/echo prune and per-turn PMI as chat.
Primary: receiver says any fixed whole-word scoring form of partner item before partner does, in six free greedy turns. Nonempty partner items define denominator. No requirement that text semantically attributes the item correctly; lexical measure only. No LLM judge. Original string-city behavior remains unchanged.
Controls: link cut with adapters active, isolated crossed partner independently rejection-drawn with same opener and same private-item kind, different value and non-overlapping scoring forms from focal target/receiver item; donor prompt cannot contain focal target form. Null-target chats remain in collapse summaries.
Inference: paired names(link)-names(control), exact one-sided positive sign test on discordant receiver outcomes, separately per receiving model; ties excluded. Counts and denominators by kind and by held-out versus trained kind, no pooling of the two correlated receivers for inference. Per-kind tests exploratory; no multiplicity-corrected discovery claim.
Exposure: record whether any target form occurs in receiver prompt; retain draws as legacy chat does. Report exclusive subset separately for chat2. Training kind means private-item assignment in chat2, not absence of that topic from pretraining or other games.
Training: fixed 300 optimizer steps from nl22c step_157, nl22 mix plus chat2=.25; no time-based schedule adaptation or checkpoint selection by test outcomes. Evaluate same 40 draws before/after, 3 deterministic disjoint shards, link/cut/crossed. Payload table as existing nl22.
Timing: benchmark real tiny models and real teacher likelihood operations, no fake generation; tiny random model prune survival is not a quality estimate. GPU time is an explicit unmeasured planning estimate, never inferred as a measured hardware speed ratio from tiny CPU timing.
